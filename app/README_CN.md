# 宝可梦 bot 使用说明

## Windows 启动

1. 把整个 ZIP 解压到一个普通文件夹，不能直接在压缩包里运行。
2. 双击 `StartBot.cmd`。
3. 输入 `3`：同时接测试赛与正式比赛；`1` 只接测试，`2` 只接正式，`4` 检查连接，`5` 离线自检。
4. 粘贴平台的 Official Agent Key。输入时不显示字符；按回车即可。它只放在进程内存，不保存到文件。
5. 保持窗口打开，电脑联网、不休眠。平台有已分配的宝可梦比赛后，会自动接入。

包里已经包含 Windows Python 和依赖，无需另装 Python，也不用 OpenAI API Key。`runtime/` 和 `app/` 必须与启动文件放在一起。

这是 Windows 便携运行包，入口是 CMD，不是单文件 EXE。构建环境是 Linux，尚未在真实 Windows 系统运行；请先双击 `CheckWindows.cmd` 自检，再选 `4` 检查平台连接。这里没有你的平台密钥，也没有代你完成平台对局。

## 策略做了什么

选秀同时考虑单体强度、队伍搭配、属性覆盖、天气和空间、击掌奇袭、掩护、控速、道具冲突和对手接下来可能抢的牌。选人阶段比较全部六选四及首发组合。对战阶段把两只精灵的动作一起计算，再与多种对手回应比较，估算击杀、换人、保护、集火和场面收益。

对战计算先比较本回合的联合动作，再对部分候选估算下一回合的攻击收益，让空间、控速、保护和换人能够计入后续价值。第二回合只搜索少量攻击组合，不穷举所有保护、铺场和换人；伤害和机制也是近似模型。实测结果见 `VALIDATION.md`；本地对基础策略的结果不等于正式平台胜率，更不能保证必胜。

## 和红警一起用

这个独立包只认领宝可梦比赛。旧红警程序可能还会接管所有游戏，所以不要让两个程序同时争同一宝可梦席位。

如果使用红警源码版，可把本包 `app/pokemon_bot/` 复制到红警源码根目录，设置 `REDALERT_OTHER_AGENT=pokemon_bot.agent`，仍用红警入口运行。该配置适用于红警加宝可梦，不包含狼人杀。旧的打包 EXE 需要重新构建才能带上新模块。

本次没有改动你的红警仓库或现有 EXE。

## 日志

从菜单启动时，本方观察、动作和搜索摘要写入 `app/logs/`。不写登录请求或密钥，不读取观众视角，也不把上局观察带入下一局。后续可用这些日志复盘改进策略。日志里的动作记录是“计划提交”，不能单独证明服务器已经接受。

正式上线前需要在平台完成 Self-hosted 设置、对应比赛报名、源码仓库和提交版本登记。按平台当时公布的截止时间操作。
